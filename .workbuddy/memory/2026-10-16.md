# 2026-10-16 — DailyLingo 全站实现

## 交付内容
从零实现 DailyLingo 纯静态英语学习网站（GitHub Pages 项目站点）。

- `scripts/build.py`：Markdown 解析 → 编号校验 → Chapter 分组（每 100 号一段，只输出含
  真实文章的分组）→ 生成 `index.html` + `src/*.html`（五个固定区域）→ 关联 `sources/*.wav`
  → 自动上下篇导航。仅用标准库。
- `scripts/validate.py`：146 项端到端校验（PASS 146 / FAIL 0 / WARN 0）。
- `tests/test_build.py`（80 例）+ `tests/test_frontend.py`（4 例，在 Node 中真实执行
  `assets/js/main.js` 的 `judge()` 与 `normalizeAnswer()`）→ `pytest -q` 84 passed。
- `assets/css/style.css`、`assets/js/audio-player.js`（真实 WAV 播放：进度/拖动/±5s/
  0.75x~2x/音量/结束与错误态）、`assets/js/main.js`（判分）。
- `README.md`：目录、编号规则、md 格式、分组算法、播放器、命令、实测结果、部署、人工待验项。

## 关键约定（后续维护必读）
- `content/` 是文章唯一维护源；`src/` 与 `index.html` 是**生成物，必须提交**（Pages 直接
  以仓库根为站点根）。`sources/` 放 WAV。
- Markdown 兼容 `D:\user_project\git\DailyWork\english` 的既有格式：`# 标题` +
  `## Article / Words / Questions / Answers / Continues`；也支持 YAML front matter 与
  `## Q1` + `题型：单选/填空` + `可接受答案：` 扩展格式。答案支持紧凑字母串（`BAC`）、
  `Question5: …`、分块三种写法，可混用。
- 音频由外部工具 `009.ai_voice` 的 `publisher\eaudio.cmd` 生成（读 `## Article` 章节，
  输出与 md 同名的 WAV）；构建脚本**不做** TTS / 转码。
- 全站相对路径，禁止 `href="/…"`；`validate.py` 会检查。
