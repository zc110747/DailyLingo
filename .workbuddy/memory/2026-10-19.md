## 桌面端（apps/windows，WinForms + WebView2）

### 需求
外壳直接吃线上站点；未联网显示「请连接网络，当前无资源」；发布到 `apps/windows/publisher`；
进度存 exe 同目录 JSON，格式与网页端导出**一致**。

### 关键实现
- **三态界面**：`SplashView`（渐变 `Lingo` + 音量条动画 + 状态文字）/ 网页 / 错误菜单。
  **导航成功才显示 WebView**，所以不再出现「先白屏、再出页面」——这一条是用户反馈的核心。
- 启动顺序：Splash → 初始化 WebView2 → 探测网络（网卡状态 + 对站点 6 s GET）→ 导航 →
  25 s 看门狗。超时/失败都落到同一个错误菜单，附失败原因与「重新连接（F5）」。
- **进度镜像**：`AddScriptToExecuteOnDocumentCreatedAsync` 在页面脚本前把文件内容写进
  `localStorage`（文件为权威副本）；钩 `Storage.prototype.setItem` + 2 s 轮询兜底 →
  `postMessage` → 宿主校验后原子落盘（`.tmp` + `File.Move`）。
- **序列化对齐网页导出**：2 空格缩进、键序 `schemaVersion/completedArticles/updatedAt/exportedAt`、
  结尾换行、UTF-8 无 BOM；损坏文件备份成 `dailylingo-progress.corrupt-<时间戳>.json` 后忽略。

### 验证（可复现）

- `--render-preview <dir>`：把启动页离屏渲染成 PNG，肉眼核对版式（不建窗口）。

### 环境坑
- **GUI 进程活不过工具调用**：`(exe &)` 起的进程在命令结束、或下一次调用前被回收，
  因此验证必须在**同一次调用**里完成「启动 → 等待 → 截图 → 结束」。
- **PowerShell 工具禁用 `Add-Type`**（"compiles and loads .NET code at runtime"）⇒ 需要 Win32 API
  时改用 Python `ctypes` + Pillow `ImageGrab`，不要走 PowerShell 的 `Add-Type`。
- **屏幕截屏抓不到自己的窗口**：用户桌面上其它窗口压在上面，`SetForegroundWindow` /
  `SetWindowPos(HWND_TOPMOST)` 都不保证生效。要看 WebView 内容就用 `CapturePreviewAsync`
  直接导出，绕开 z-order。
- 首次截到的启动页上有一圈青边框，取样像素后确认是**抓屏瞬间的 DWM 残影**，不是控件画的
  （后续同位置采样全是 `#F7F9FC`）。

## Android 端

### 交付
- `apps/android/`：系统 WebView 外壳，包名 `com.dailylingo.app`，minSdk 24 / targetSdk 36，
  发布 `publisher/DailyLingo.apk`（69 KB，不依赖 AndroidX / Material / Gradle）。
- 流程与 Windows 端一致：Lingo 启动页 → 探网（系统网络能力 + 站点 6 s GET）→ 导航成功才显示网页；
  离线 / 25 s 超时 → 错误菜单「请连接网络，当前无资源」（重新连接 / 在浏览器中打开）。
- 进度镜像 `/sdcard/Android/data/com.dailylingo.app/files/dailylingo-progress.json`，
  钩 `Storage.prototype.setItem` + 1.5 s 轮询；网页存储为空时写种子并重载一次。

### 构建（本机无 Gradle）
- SDK 工具链手搓：`aapt2 compile/link → javac → d8 → zip 追加 classes.dex → zipalign → apksigner`，
  `tools/build_apk.py` 只用标准库。
- SDK 走 `ANDROID_SDK_ROOT` / `--sdk`；JDK 走 `JAVA_HOME` / `--jdk` / Studio 的 `jbr`。
  本机 JDK 25 下 `javac -source 17 -target 17 -classpath android.jar` 与
  `java -cp lib/d8.jar com.android.tools.r8.D8` 都能直接跑，比调 `.bat` 稳。
- 固定 `keystore/dailylingo-debug.keystore`（android /android），否则 `install -r` 签名冲突。
- `--v4-signing-enabled false`：默认会多出一个 `.idsig`，无用。

### 真机（vivo V2241A / Android 16 / API 36 / 1080×2400 / 480dpi）
- 联网：20 篇、进度卡 0/20、Chapter 计数正常。
- 点第一篇勾选 → 文件出现 `["0001"]`；再点取消 → `[]`；`od -c` 确认 `Z"\n}\n`（**LF 结尾**）。
- 离线：`--ez force_offline true` → 错误菜单，进度提示「本机尚未保存学习进度」。

### 三个真机坑
1. **`getWindow().getInsetsController()` 在 `setContentView` 之前是 NPE**（DecorView 为 null），
   崩在 `setUpWindow`。改 `getDecorView().getWindowInsetsController()` 并挪到 `setContentView` 之后。
2. **WebView 用 `INVISIBLE` 隐藏仍参与合成**，会盖住启动页 → 启动一片空白（连拍三张全白）。
   改 `GONE` 后正常（日志 `启动页首帧：1080x2286`，用户目视也确认）。
3. **桌面图标白边**：源 favicon 本身是「蓝底圆角 + 白书本」，外面又垫白画布并缩到 88%，

   另：`.gitignore` 的 `tools/` 会把 `apps/android/tools/` 一起忽略 → 改 `/tools/`。
