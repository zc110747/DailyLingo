## 新增 0086–0090；fix_content 支持「无扩展名」文件

- 用户这次丢进来的五篇**连 `.md` 扩展名都没有**：`content/0076-0100/0086 … 0090`（文件名就叫 `0086`）。
  `build.py` 只扫 `*.md`，这类文件会被**静默跳过**（不报错、也不出现在首页），拿 `ls content/*.md`
  数篇数会少 5 篇却看不出问题。
- 改法：`scripts/fix_content.py` 抽出 `_article_files()`，除 `*.md` 外也收 `纯数字无扩展名` 的文件；
  `scan()` 的编号正则从 `^(\d+)\.` 放宽成 `^(\d+)(?:\.|$)`。改名后自然变成 `NNNN.Slug.md`，
  构建随即能认。配套新增用例 `test_file_without_extension_is_renamed`（fix_content 15→16 例）。
- 归一结果：`0086.How_Does_GPS_Help_Us_Find_Places` / `0087.Why_Does_the_Moon_Change_Its_Shape` /
  `0088.How_Do_Thunderstorms_Happen` / `0089.What_Happens_at_the_Beach` /
  `0090.A_Perfect_Weekend_at_the_Botanical_Garden`。
- 这批的 Continue 又是**另一套模板**：`- [Catalogue](./catalogue.md)` / `[Previous chapter]` /
  `[Next chapter]`（首字母大写、全指 catalogue.md），previous 也照例错位（0086 指向 0077）。
  脚本统一改写成小写标签 + `../../index.html` + 相邻编号，**270 条 md 链接 0 broken**。
- 内容：每篇 6 道单选题（无填空）、正文 0 中文、**无对话体标签**、行尾 LF（无需归一）。
