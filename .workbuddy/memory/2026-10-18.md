### 0016 文件名踩坑（这轮最值得记）
- 用户给的文件名是 `0016.Grandma’s_Secret_Recipe.md`，**撇号是 U+2019 弯撇号**。
- 第一反应改成 ASCII 撇号 `Grandma's_...md` ⇒ 构建后 `validate.py` 报 **3 个 FAIL**
  （首页链接、上一篇/下一篇、音频路径）——因为 `esc()` 把 `'` 转成 `&#x27;`，
  而断言拿原始文件名去比对。
- 最终改成 **无撇号** `0016.Grandmas_Secret_Recipe.md`（H1 保留 `Grandma’s` 排版撇号，
  显示标题不受影响）。理由：文件名同时是 **URL 片段**和**音频文件名**，非 ASCII 标点会
  多出一层 percent-encoding（`%E2%80%99`）+ git 引号 + HTML 转义三个面，收益为零。
  沿用 0006「含空格 → 下划线」的改名先例。
- 改名配套动作（都做了）：改 0015 的 `## Continue` 交叉引用 → 删旧 WAV → 用新名字重新生成
  → **删孤儿页 `src/0016.Grandma's_Secret_Recipe.html`**（构建不删文件，改名必留孤儿）。
