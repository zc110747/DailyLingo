### 入库前修掉的两类问题（都是构建/链接会出错的）

1. **文件名带 ASCII 撇号**：`0039.The_Town's_New_Recycling_Center.md` → `The_Towns_...`
   （文件名同时是 URL 片段与音频名；H1 保留 `The Town's ...`，同 0016 的处理）
2. **10 篇的 `## Continue` 全写错**：`catalogue` 与 `next chapter` 都指向 `./catalogue.md`
   （仓库根本没有这个文件），实际约定是 `../index.html`。按编号相邻统一重写：
   * `catalogue` → `../index.html`
   * `previous chapter` → 上一篇（缺号则 `../index.html`）
   * `next chapter` → 下一篇，最后一篇 0040 → `../index.html`
   * 顺带把 **0030 的 next 改指 0031**（它原来是末篇，指向首页）

   做法：一段 Python 脚本按 `content/*.md` 排序建 `names[number]` 映射，正则只替换
   `## Continue` 到文末，其余正文一字不动。
